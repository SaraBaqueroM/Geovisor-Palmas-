# Distribución potencial de palmas amenazadas en Colombia mediante Inteligencia Artificial

## Descripción

Proyecto desarrollado en el marco del Concurso Datos al Ecosistema 2026.

Este proyecto busca integrar datos abiertos de biodiversidad provenientes de GBIF con herramientas de análisis espacial y aprendizaje automático para evaluar patrones de distribución de palmas amenazadas en Colombia.

## Objetivo

Construir un flujo reproducible para analizar registros de ocurrencia de especies de palmas y explorar variables ambientales asociadas a su distribución.

## Datos utilizados

- GBIF Occurrence Data
- Información taxonómica
- Variables ambientales
- Estado de amenaza de especies

## Metodología

El proyecto sigue el marco CRISP-ML:

1. Comprensión del problema
2. Comprensión de los datos
3. Preparación de datos
4. Modelamiento
5. Evaluación
6. Comunicación de resultados
