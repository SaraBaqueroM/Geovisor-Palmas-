# Código fuente

Esta carpeta está destinada al almacenamiento de módulos reutilizables del proyecto.

Durante el desarrollo de esta versión, la mayor parte del flujo de trabajo fue implementada mediante scripts independientes ubicados en la carpeta `Scripts/`.

En futuras versiones, estos scripts podrán modularizarse dentro de esta estructura para facilitar su reutilización, mantenimiento y escalabilidad.
