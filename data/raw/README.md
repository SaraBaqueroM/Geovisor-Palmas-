# Datos originales

Esta carpeta contiene los datos descargados directamente desde las fuentes oficiales.

Fuentes principales:
- Especies amenazadas descargadas de datos.gov.co
- GBIF: registros de ocurrencia de especies.
- IDEAM: alertas tempranas de deforestación.
- Fuentes geográficas complementarias.

Los archivos almacenados aquí corresponden a datos sin modificaciones.
